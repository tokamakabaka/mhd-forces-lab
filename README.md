## 核心物理

对随流体运动的材料体积：

```text
d/dt ∫V ρv dV = ∫V (ρg + J×B) dV + ∮∂V t(n) dS
t(n) = σ·n,    σ = −pI + τ
∮∂V σ·n dS = ∫V ∇·σ dV
```

得到单位体积的 MHD 动量方程：

```text
ρ Dv/Dt = −∇p + ∇·τ + J×B + ρg
```

- **热压力** `−∇p`：来源是边界上的法向接触力，属于**表面力**；经散度定理后写成体积分形式的力密度。
- **粘滞力** `∇·τ`：来源是边界上的切向接触力，属于**表面力**；不可压牛顿流体中为 `μ∇²v`。
- **洛伦兹力** `J×B`：作用于体积内每个电流元，不需要边界接触，属于**体积力**。
- **重力** `ρg`：作用于每个质量元，属于**体积力**。

电磁力的另一种记账方式：

```text
J×B = −∇(B²/2μ₀) + (B·∇)B/μ₀
      磁压梯度          磁张力
```

两项的平行于磁场的分量恰好抵消，净洛伦兹力始终垂直于 `B`。这没有把 `J×B` 变成表面力，只是把它写成 Maxwell 应力张量的散度。

场的动量账本：

```text
f = ρ_e E + J×B
g = ε₀ E×B = S/c²
T_ij = ε₀(E_iE_j − ½δ_ijE²) + (1/μ₀)(B_iB_j − ½δ_ijB²)
f + ∂g/∂t = ∇·T
静态场：f = ∇·T
MHD 极限：T_M = (1/μ₀)(BB − ½B²I),  ∇·T_M = J×B
```

图片符号版：

```text
mn du/dt = nF − ∇p − ∇·Π↔ + R
F = q(E + u×B)
```

其中 `n` 是数密度，`m` 是单粒子质量，`mn = ρ`；`p` 是压强张量对角项；`Π↔` 是非对角偏应力；`R` 是异种粒子碰撞摩擦。若采用 `σ = −pI + τ`，则 `Π↔ = −τ`。

## 波与 MHD 实验室模型

### 离子声波（1D 准中性离子流体）

```text
∂t n + ∂x(nu) = 0
∂t u + u ∂x u = −(1/n)∂x n − νu
E = −(1/n)∂x n          (ambipolar)
```

取 `c_s = 1`，离子有惯性、电子无惯性；长波极限 `ω = k c_s`。代码用 256 点迎风有限体积；`E` 是电子压力平衡得到的 ambipolar 场。

### 1D 磁声波（可压缩理想 MHD）

```text
∂t ρ + ∂x(ρu) = 0
∂t(ρu) + ∂x(ρu² + p + B²/2) = 0
∂t B + ∂x(uB) = 0
∂t E + ∂x[(E + p + B²/2)u] = 0
```

磁场垂直于传播方向；HLL 有限体积。力预算：

```text
ρ Du/Dt = −∂x p − ∂x(B²/2)
```

画面同时显示 `ρa`、`−∂x p`、`−∂x(B²/2)` 三条曲线。

### 2D 可压缩 MHD（磁化爆炸波 + 力探针）

```text
∂t ρ + ∇·(ρu) = 0
ρ(∂t u + u·∇u) = −∇p + J×B + ν∇²u
∂t p + u·∇p = −γ p ∇·u
B = B0 x̂ + ∇×(Aẑ)
∂t A + u·∇A = −B0 uy + η∇²A,    Jz = −∇²A
```

中心压力脉冲在均匀背景场 `B0` 中膨胀；点击画布放置力探针，比较 `−∇p`、`J×B` 与 `ρa`。这是半拉格朗日定性演示，不是激波捕捉求解器。

三个模型都用周期边界、无量纲单位和实时渲染；离子声波/磁声波是一维有限体积，2D MHD 是半拉格朗日 + 源项。

## 适用边界

- 单流体、准中性、非相对论；粘性取牛顿流体形式。真实磁化等离子体的粘性与压强可能是各向异性的（Braginskii 输运），此时应使用压强张量 `P` 与 `−∇·P`。
- 2D MHD 沙盒是可压缩定性演示，不是定量预测工具；采用半拉格朗日平流和人工低通，不能替代激波捕捉/湍流求解器。
- 离子声波是准中性、长波极限；没有 Debye/Poisson、电子惯性和 Landau 阻尼。
- 1D 磁声波是理想 MHD 的 HLL 演示；磁场垂直于传播方向，因此只有磁压、没有磁张力弯曲项。
- 量级实验室使用数量级尺度：`f_B = B²/(μ₀L)` 是磁压梯度尺度；讨论感应制动时另一个常用尺度是 `σUB²`，对应相互作用参数 `N = Ha²/Re`。
- 页面中的滑块与读数使用相对单位/无量纲单位；实际工程问题需要代入具体物性、边界条件与几何。

## 主要公式速查

```text
Re  = ρUL/μ                 惯性 / 粘性
Ha  = BL√(σ/μ)              磁力 / 粘性（Hartmann 数）
N   = σB²L/(ρU)             磁力 / 惯性（相互作用参数）
Rm  = μ₀σUL                 感应 / 磁扩散（磁雷诺数）
β   = 2μ₀p/B²               热压 / 磁压
v_A = B/√(μ₀ρ)              阿尔芬速度
Eu  = Δp/(ρU²)              压力 / 惯性（欧拉数）
```
